# Doggos

A Connect IQ watch face of animated dogs. The README covers settings, setup,
`make` targets, how the dogs are rendered (Blender, `tools/blender/`) and the
code layout.

- `make test` before committing. Logic belongs in plain classes
  (`DogLayout`, `DogPicker`, `Story`) with tests in `test/`; `TEST=name` runs
  one.
- `source/Dogs.mc` and the animation resources are generated by `make art`
  from the renders. Change the rig or the tools, not the generated output.
- Rendering is slow (`make frames` is ~30 minutes): narrow it with
  `DOGS=` / `MOODS=` / `ANIMS=` while iterating.
- To review renders, use the watch-size GIFs from `make preview` /
  `make rig-preview` (`build/review/`). For more than a couple of images,
  hand them to the `image-check` agent instead of reading each one.
